# v0.1 发布与审查清单

## 必须完成

- [x] GitHub 分支和独立 PR，默认分支由仓库拥有者决定是否合并。
- [x] AES-128 / 轮密钥 / SBox / inverse SBox 以及第一轮与最后一轮的字节索引测试。
- [x] 合成迹线、SNR、NICV、TVLA 和候选密钥评分的数学单元测试。
- [ ] 远端 GitHub Actions 的 `npm install`、`npm run test`、`npm run build` 全绿。
- [ ] 实际浏览器视觉检查及键盘/移动端基本检查。
- [ ] 课程 12 章全文完成，案例和概念测验由初学者评估。
- [ ] 真实侧信道数据集的独立训练/攻击分割、可复现脚本和真实实验报告。

## 不应宣称

- 不能把玩具 Gaussian likelihood 输出称为 CNN/LNN 的训练结果。
- 不能把合成 trace 绘制的峰值称为物理设备的第一轮 SBox 泄漏。
- 不能将某一个 8-bit 子密钥排名第一称为恢复全部 AES-128 密钥。
- 不能把固定/随机 Welch t 检验峰值直接等同为最佳 PoI。

## 评审要点

所有模型输入、标签、密钥假设、泄漏区段、真实/合成来源以及是否使用目标真值均必须显式标注。
