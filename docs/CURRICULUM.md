# 教学知识依赖与章节验收

## 先修依赖

`bit/byte → XOR → AES 中间状态 → 中间值/密钥关系 → 物理泄漏 → Trace/标签 → PoI → 分类器概率 → 256 候选映射 → log 累积 → Rank/PGE → 可复现真实实验`

在用户已经掌握上述主链条之前，不应在主教学路径提前堆叠掩码、跨设备、Transformer/LNN 等高级术语。

## 教材页的固定模板

- **从疑惑出发**：这个概念要解决什么真实问题？
- **真实字节案例**：从 `P=0x2B`、`K=0x2B`、`SBox(0)=0x63` 等最小例子出发。
- **一步一解释**：点击/滑动发生可验证的数学运算。
- **严格公式**：每个变量的来源、在建模与攻击阶段是否已知。
- **常见错误**：至少反驳一个具有迷惑性的错误推理。
- **动手验证**：至少一个交互实验或可手算习题。
- **反向讲解**：给同学讲清楚这一章与上一章、下一章的联系。
