# 增量开发 Roadmap

## v0.1 · 教学闭环基础（本次）
- [x] 产品需求与教学知识地图、科研假设说明
- [x] AES-128 NIST 测试向量、逐轮运算模拟器与一个字节 ID/HW 演示
- [x] 合成 HW 型 Trace、噪声/错位与四种 PoI 指标
- [x] ID/HW 玩具概率模型、256 候选枚举、log 累积、Rank
- [x] 12 章地图、9 篇初版讲义和概念测验
- [x] CI/test/build/Pages 工作流配置
- [ ] 本地 npm 依赖安装、lockfile 提交、完整前端 build/Playwright E2E（当前执行环境无 npm 域名解析能力，需在有网络的 CI 中验证）
- [ ] 用户盲测与移动设备人工验收

## v0.2 · 深化可解释性
- 完整 AES 数据流动、每轮逐字节敏感值、末轮 ShiftRows 索引对照和可视化密钥扩展。
- PoI 多峰/多窗口、简单交叉相关对齐、泄漏模型错配、HW/HD 与字节特定泄漏差异。
- 减少课程中的术语跳跃，新增点击术语词典与学习前提检查。
- 自动生成完整测试向量、错误案例与已知/未知状态面板。

## v0.3 · 真正的深度学习 DLSCA
- Python 环境模板与公开数据集载入，不捆绑大型数据文件。
- 已标注数据 Profiling/Validation/Attack 划分和数据泄漏检测。
- MLP/CNN 训练脚本与固定配置、预测概率导出格式、前端读取模型输出。
- 在真正的预测概率上进行候选评分、排名、GE/PGE 多次随机试验。

## v0.4+ · 研究扩展
- ASCAD 脱同步/掩码数据实验，跨密钥与跨设备评估。
- Transformer/LNN 对照、模型校准、PoI 选择与分类性能/密钥恢复联合评估。
- 课程最后的自主方案设计和完整攻击实验报告。

每次 PR 都应附带具体的教学目标、科研前提、实际运行测试以及可复核的界面截图/演示。
