# 产品需求文档 · DLSCA Academy

## 一、问题与目标

目标使用者是没有 AES、SCA、深度学习背景的大学生/研究新手。他们可能连 byte、XOR、SBox、Trace、PoI 都不熟悉，却需要理解 DLSCA 的完整原理、步骤与研究评估标准。

产品目标不是“点击一次就看完”，而是让学习者能够**从原理解释，到可控实验，再到可复现数据研究**。不能假定所有用户初学一次就全部掌握；应由章节测验与综合实验客观验证。

## 二、关键用户故事

- 我从未学过 AES，希望知道一个实际字节如何流过 AddRoundKey / SubBytes，及其是否可逆。
- 我看过公式 `V = SBox(P⊕K)`，仍不理解 V 为什么帮我恢复 K，希望能亲手修改 P 和 K 并观察 V。
- 我不知道攻击最后一轮为何提到 `K10`：希望每一个阶段的“已知 / 未知 / 候选”清晰区别。
- 我只看到电磁 Trace，却不知道 SBox 在哪里，希望理解触发、对齐、PoI 统计与时序归因之间的关系。
- 我希望亲自比较 TVLA、SNR、NICV，而不仅是看哪条曲线峰值最高。
- 我想看模型输出概率如何为 256 个候选密钥逐次加分，以及 GE/PGE 与成功率的区别。
- 我希望最终自己在公开数据集上完成可复现的深度学习侧信道实验，并能解释整个实验协议。

## 三、教学设计约束

每节讲解应有：问题引入 → 必要前提 → 数值案例 → 可操作交互 → 数学表达 → 误区与限制 → 能否讲给别人听的检查。首次出现术语必须解释，不在同一屏突然引入多种新记号。

必须明确区分：真实已知建模密钥、目标真实未知密钥、候选猜测 `k`；物理泄漏模型与机器学习标签表示；模型分类准确率与密钥恢复性能；检测泄漏与定位某个目标运算；合成数据与真实观测。

## 四、功能范围与验收标准

### 第一批（本次 v0.1）

- 响应式课程界面、12 章路线、初版已开放讲义、练习与本地阅读进度。
- 真实 AES-128 加密逐步执行，至少与 NIST 测试向量一致。
- 带固定随机种子的合成 HW 型泄漏，控制噪声、错位、并实时计算多个 PoI 指标。
- 透明高斯似然教学分类器输出 ID/HW 概率分布，逐样本遍历 256 候选，正确累计 log 概率。
- 通过纯函数单元测试验证核心运算；配 CI 构建与测试脚本。

### 第二批

- 完整 16 字节 AES 轮级 / 密钥扩展可视化；首轮/末轮与 ShiftRows 索引对照。
- 不同泄漏模型的物理假设实验（HW、HD、bit-specific、多时刻状态变化）。
- PoI 校验、迹线对齐、不同窗口和基线方案独立验证；TVLA、多重比较及估计稳定性教学。
- 初级 MLP/CNN 真实训练模块（Python/Colab），模型概率文件导入前端用于独立的候选评分。

### 第三批与以后

- ASCAD（按照官方格式和许可使用）的可复现实验；明确 profiling/validation/attack 协议；GE/PGE 重排统计。
- 深度学习分类性能、攻击性能、跨设备泛化对比；LNN、Transformer、掩码与对策。
- 综合毕业实验、练习记录和正式的“反向讲解”评分量表。

### 必要质量门槛

1. 算法测试：AES FIPS 向量、逆 SBox、密钥扩展、标签计算、候选得分顺序。
2. 统计测试：SNR/NICV/TVLA 结果为有限值；至少能在低噪声无错位合成场景定位预先注入的目标泄漏位置。
3. 学术核查：核心定义提供参考；虚构迹线 / 玩具模型明确标注；不得声称 Rank=0 等价于 128-bit 全密钥恢复。
4. 教学核查：试用学习者能在不用看答案时解释至少五个关键“为什么”，并能够手算一个 AES 子密钥的候选评分。
5. 工程核查：现代浏览器可运行、交互有键盘/可访问标签、手机端布局不溢出、CI 测试通过。

## 五、非目标

v0.1 不包含真实神经网络训练、不保证在实际设备上恢复任何秘密密钥、不作为已完成的全面课程认证平台。后续实验必须明确合法授权与科研复现条件。
